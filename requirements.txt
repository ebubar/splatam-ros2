# CUDA rasterizers are NOT listed here on purpose. They are CUDA extensions that
# must be built against your installed torch + GPU arch, and pinning them here
# makes `pip install -r requirements.txt` fail on a build step. Install them with
# the dedicated installer, which sets TORCH_CUDA_ARCH_LIST for your GPU:
#
#     bash bash_scripts/install.bash                 # core deps + gsplat (default engine)
#     bash bash_scripts/install.bash --with-cuda-fallback   # also the optional INRIA rasterizer
#
# - gsplat (Apache-2.0) is the DEFAULT engine for scripts/zed2i_gsplat_live.py.
# - diff-gaussian-rasterization (INRIA, research/non-commercial) is only the
#   optional "cuda" fallback backend, built from third_party/diff-gaussian-rasterization.
#   You do NOT need it for the default gsplat path.
